# Game Boy Palettes Archive

An archive of Game Boy palettes from various creators, collections and sources.

This repository preserves palette collections that may no longer be available from their original sources, while also providing archived images and ready-to-use palette files where available.

## About

This repository is an archive of Game Boy palette collections from various sources.

The goal is to preserve palette artwork and data that may otherwise become unavailable, while crediting the original creators and sources wherever possible.
